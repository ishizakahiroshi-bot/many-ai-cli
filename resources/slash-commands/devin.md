# Devin Slash Commands

| Command | Purpose | When to use it |
|---|---|---|
| `/help` | Show help and available commands. | When checking what the CLI can do. |
| `/clear` | Start a fresh conversation. | When beginning a new task. |
| `/compact` | Compact conversation history. | When reducing context usage. |
| `/model` | Switch the active model. | When changing models mid-session. |
| `/exit` | Exit the CLI. | When finishing work. |
